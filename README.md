# Chalkline

Draw a line. Ride it.

A stick figure on a sled follows whatever hill you sketch. Keep drawing while they ride. Ice is slippery, springs launch you, and a gap turns the rider into a ragdoll.

## Play

```bash
npm install
npm run dev
```

Then open the app and press play. Draw with the pencil, switch to ice or spring ink, and try the built-in tracks.

## Controls

- Draw, straight line, erase, or pan
- Play / pause, slow motion, and a kick
- Undo, clear, and reset the rider
- Tracks: First hill, and a blank page
